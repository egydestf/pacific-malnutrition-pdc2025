## Half Fed, Half Forgotten: The Untold Story of Malnutrition in the Pacific

This project is a personal submission for the **Pacific Dataviz Challenge 2025**, created to spotlight the persistent issue of malnutrition and food insecurity in Pacific Island nations through interactive and narrative-driven storytelling.

🌀 Built with simple HTML, CSS, & JS  
📊 Visualizations created using [Flourish](https://flourish.studio)  
📝 Scroll-based, story-focused layout  

### 📁 Data Source

- [Pacific Data Hub](https://pacificdata.org/data/dataset/sustainable-development-goal-02-zero-hunger-df-sdg-02)
