## Half Fed, Half Forgotten: The Untold Story of Malnutrition in the Pacific

This project is a personal submission for the **Pacific Dataviz Challenge 2025**, built to explore the intersection of data, storytelling, and nutrition issues in the Pacific region.

🌀 Developed with HTML, CSS, and interactive visualizations using Flourish.  
✍️ Narrative-driven, scroll-based layout.  
📊 All visual assets and data belong to their respective sources.

**Note:** This is a non-commercial, educational project.  
We acknowledge there may be imperfections, and we welcome feedback.
